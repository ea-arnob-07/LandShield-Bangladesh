## 📌 পরিচিতি ও একনজরে প্ল্যাটফর্ম

**ল্যান্ডশিল্ড বাংলাদেশ (LandShield - BhumiSeba)** হলো নাগরিক ও প্রশাসনের জন্য তৈরি একটি সর্বাধুনিক, স্বয়ংসম্পূর্ণ ও বুদ্ধিমত্তা-চালিত ডিজিটাল ভূমিসেবা ইকোসিস্টেম। এতে ভূমির দলিলপত্র বিশ্লেষণ, বাংলা ও ইংরেজি অপটিক্যাল ক্যারেক্টার রিকগনিশন (OCR), ইন্টারেক্টিভ ক্যাডাস্ট্রাল জিআইএস ম্যাপ, মৌজা-দাগ-খতিয়ান ট্র্যাকিং, উত্তরাধিকার ক্যালকুলেটর এবং প্রাতিষ্ঠানিক অডিট ব্যবস্থার সমন্বয় ঘটানো হয়েছে।

## 🚀 দ্রুত শুরু করুন (Quick Start Guide)

### ১. পূর্বশর্ত
- **Node.js**: সংস্করণ `v24.0.0` বা এর পরবর্তী (বিল্ট-ইন `node:sqlite` সাপোর্টের জন্য)।
- **npm**: আধুনিক প্যাকেজ ম্যানেজার।

### ২. ইনস্টলেশন ও ডিপ্লয়মেন্ট

```bash
# ১. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ২. লোকাল সার্ভারে ডেভেলপমেন্ট মোডে লাইভ করুন
npm run dev
```

সার্ভার সফলভাবে চালু হলে আপনার ব্রাউজারে খুলুন:
👉 **`http://localhost:4173`**

### ৩. প্রোডাকশন বিল্ড ও প্রিভিউ

```bash
# টেস্ট সুট চালান (৭০টি টেস্ট সম্পূর্ণ পাস)
npm test

# সম্পূর্ণ প্রোডাকশন অপ্টিমাইজড বান্ডিল তৈরি করুন
npm run build

# বিল্ট প্রোডাকশন সার্ভার প্রিভিউ করুন
npm run preview
```

## ✨ প্রধান ফিচার ও মডিউলসমূহ

### 📑 ১. ইন্টেলিজেন্ট দলিল প্রসেসর ও OCR ল্যাব
- **মাল্টি-ফরম্যাট সাপোর্ট**: স্মার্টফোন ফটো, স্ক্যান কপি, PDF, DOCX, TXT এবং WebP ফাইল গ্রহণ করে।
- **দ্বিভাষিক OCR**: বাংলা ও ইংরেজি দলিলের হাতের লেখা বা প্রিন্ট থেকে স্বয়ংক্রিয়ভাবে দলিল নম্বর, তারিখ, মৌজা, খতিয়ান, দাগ ও চৌহদ্দি আলাদা করে।
- **ডকুমেন্ট এক্সপোর্ট**: প্রফেশনাল ফরমেটেড বাংলা PDF এবং সম্পাদনযোগ্য Microsoft Word (DOCX) রিপোর্ট তৈরি।

### 🗺️ ২. ক্যাডাস্ট্রাল ম্যাপ ও জিও-লোকেশন ইঞ্জিন
- **বাংলাদেশ মানচিত্র**: প্রতিটি জেলা, উপজেলা ও মৌজা পর্যায়ে জুম ও পিন পয়েন্ট সিলেকশন।
- **লাইভ জিপিএস লোকেশন**: আবেদনকারী নিজের বর্তমান অবস্থান বা জমির নির্দিষ্ট স্থান পিন করে আবেদনে সংযুক্ত করতে পারেন।
- **স্থানাঙ্ক সাপোর্ট**: বাংলা ও ইংরেজি উভয় ফরম্যাটের অক্ষাংশ ও দ্রাঘিমাংশ (Latitude/Longitude) গ্রহণ করে।

### 🏢 ৩. আঞ্চলিক অফিস ও কর্মকর্তা ডিরেক্টরি
- আবেদনকৃত জমির সংশ্লিষ্ট এসি (ল্যান্ড) অফিস, সাব-রেজিস্ট্রি কার্যালয় এবং সার্ভেয়ারদের সঠিক যোগাযোগের তালিকা।
- জাতীয় ভূমি সহায়তা হটলাইন **১৬১২২** সরাসরি সংযুক্ত।

### 🏛️ ৪. ১৩টি বিশেষায়িত ভূমিসেবা মডিউল
1. **স্মার্ট নামজারি (Smart Mutation)**: নামজারি আবেদন প্রক্রিয়ার ধাপ ও সম্ভাব্য সময়সীমা ট্র্যাকিং।
2. **ভূমি উন্নয়ন কর (LD Tax)**: করের দাবি ও রশিদ যাচাইয়ের নমুনা সিমুলেশন।
3. **উত্তরাধিকার ক্যালকুলেটর (Inheritance Engine)**: মুসলিম ও পারিবারিক আইন অনুযায়ী জমির অংশের ডিজিটাল হিসাব।
4. **ক্রেতার সতর্কতা ও যাচাই (Buyer Safety Check)**: জমি ক্রয়ের পূর্বে ৭টি গুরুত্বপূর্ণ ঝুঁকি ও লিগ্যাল চেকলিস্ট।
5. **সীমানা ও নদীভাঙন নজরদারি (InSAR Coastal Erosion)**: নদীভাঙন ও ভাঙনকবলিত এলাকার অবস্থান বিশ্লেষণ।
6. **প্রবাসী সেবা ডেস্ক (Diaspora Helpdesk)**: প্রবাসী বাংলাদেশিদের জমি সংক্রান্ত অভিযোগ ও ট্র্যাকিং।
7. **বিরোধ ও ক্যভিয়েট ম্যানেজার (Dispute Manager)**: জমিজমা সংক্রান্ত অভিযোগ পর্যালোচনা।
8. **ডিজিটাল ল্যান্ড রেকর্ড (Cadastral Explorer)**: খতিয়ান ও পর্চা অনুসন্ধানের ইন্টারফেস।
9. **ই-দলিল ভিউয়ার (Deed Studio)**: মূল দলিলের পাতা উল্টে দেখার ইন্টারফেস।
10. **নিরাপদ লেনদেন এসক্রো (Escrow Wizard)**: নিরাপদ ক্রয়-বিক্রয়ের আর্থিক ধাপ।
11. **অডিট লেজার (Audit Ledger)**: প্রতিটি পর্যালোচনার অপরিবর্তনীয় অডিট লগ।
12. **গভর্নমেন্ট API স্যান্ডবক্স (Gov API Sandbox)**: ডেভেলপারদের জন্য ইন্টারফেস টেস্ট প্ল্যাটফর্ম।
13. **কমান্ড ও সিটিজেন ড্যাশবোর্ড (Integrated Command Center)**: কেন্দ্রীয় তথ্যায়ন।

## 🔐 নিরাপত্তা ও গোপনীয়তা নীতি (Privacy First Architecture)

- **ব্যক্তিগত ডেটা আইসোলেশন**: নাগরিকের সংরক্ষিত কোনো তথ্য অনুমতি ছাড়া জনসমক্ষে বা অন্য ব্যবহারকারীর সাথে শেয়ার হয় না।
- **মানবসদৃশ যাচাই**: প্রশাসনিক যেকোনো সিদ্ধান্ত গ্রহণের জন্য কেবল স্বয়ংক্রিয় ফলাফলের ওপর নির্ভর না করে দায়িত্বপ্রাপ্ত কর্মকর্তার মানবীয় পর্যালোচনা বাধ্যতামূলক।
- **প্রমাণপত্রের বিশ্বস্ততা**: আপলোডকৃত প্রতিটি দলিলের ক্রিপ্টোগ্রাফিক SHA-256 চেকসাম সংরক্ষণ করা হয় যাতে কোনো প্রমাণ পরিবর্তন না ঘটে।
