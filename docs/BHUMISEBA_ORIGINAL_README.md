# LandTech · ভূমিসেবা

বাংলাদেশের ভূমি তথ্য ও সেবার একটি **ধারণাগত ইন্টারঅ্যাকটিভ ডেমো**। এটি সরকারি পোর্টাল নয়; প্রদর্শিত জমির রেকর্ড, পরিচয়, হিসাব, আবেদন, অনুমোদন ও দাগের সীমানা নমুনা। বাস্তব লেনদেন বা আইনি সিদ্ধান্তের জন্য সংশ্লিষ্ট সরকারি রেকর্ড যাচাই করতে হবে।

## চালু করুন

Node.js 20.19+ বা 22.12+ প্রয়োজন।

ইন্টারফেসে আগের LandShield/LandTech ভিজুয়াল স্টাইল—গাঢ় হেডার, মানচিত্রের ব্যানার, নমুনা তথ্যের সারি ও সেবা কার্ড—ব্যবহার করা হয়েছে। দিনের/রাতের থিম স্থানীয় ব্রাউজারে সংরক্ষিত থাকে।

```bash
npm ci
npm run dev
```

বিল্ড যাচাই ও স্থানীয় প্রিভিউ:

```bash
npm run build
npm run preview
```

## ডেমোতে কী আছে

- পাবলিক হোম, ভূমি সেবার তালিকা, মৌজা/দাগ/খতিয়ান দিয়ে নমুনা অনুসন্ধান, নির্দেশিকা, ফি তথ্য, FAQ ও সহায়তা।
- বাস্তব স্যাটেলাইট চিত্র ও জায়গার নামসহ ইন্টারঅ্যাকটিভ মানচিত্র; রাস্তার মানচিত্রে যাওয়ার বিকল্প।
- দশটি নমুনা ভূমিকার ড্যাশবোর্ড; জমির প্রোফাইল, GIS, দলিল বিশ্লেষণ, কেনাবেচা, নামজারি, কর, বিরোধ, উত্তরাধিকার, নদীভাঙন, প্রবাসী সেবা, অডিট ও API স্যান্ডবক্সের ইন্টারফেস।
- বাংলা/ইংরেজি UI। নমুনা ভূমিকায় ঢুকতে লগইন মডালের যেকোনো ভূমিকা বেছে নিন। ডেমো প্রোফাইলের জন্য শুধু ডাকনাম ব্যবহার করুন।

## মানচিত্র ও ডেটার সীমা

স্যাটেলাইট বেস লেয়ার EOX::Maps-এর EOxCloudless Sentinel-2 imagery; তার ওপর EOX-এর OpenStreetMap উৎসের জায়গার নামের স্তর। রাস্তার বেস লেয়ার OpenStreetMap standard tiles। মানচিত্রের কোণায় উৎসের স্বীকৃতি দেখানো হয়। ইন্টারনেট ও তৃতীয় পক্ষের tile/WMS সেবার ওপর লেয়ার লোড নির্ভর করে। স্যাটেলাইট স্তর না এলে স্বয়ংক্রিয়ভাবে রাস্তার মানচিত্রে যায়; সেটিও ব্যর্থ হলে OpenStreetMap লিংক রয়েছে এবং লেয়ার বোতাম দিয়ে আবার চেষ্টা করা যায়।

জমির ডেমো polygon ডিফল্টে বন্ধ এবং কেবল নমুনা প্লট বোতাম দিয়ে চালু হয়। এটি প্রকৃত cadastral survey, দাগের আইনি সীমানা বা মালিকানার প্রমাণ নয়। এই ফ্রন্টএন্ডে সরকারি রেকর্ড API, বাস্তব NID যাচাই, পেমেন্ট গেটওয়ে, স্থায়ী ডেটাবেস বা সার্ভার নেই। কোনো বাস্তব NID, পাসওয়ার্ড বা সংবেদনশীল দলিল ব্যবহার করবেন না।

## প্রযুক্তি

React 19, TypeScript, Vite, Tailwind CSS, Leaflet। কোডের প্রধান অংশ `src/`, নমুনা ডেটা `src/data/`, স্ট্যাটিক সম্পদ `public/`।
